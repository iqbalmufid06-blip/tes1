## Description — core features (bold)

- **Live Fleet Map** - see every vehicle, route, and ETA in real time on one screen.
- **Delivery Management** - assign jobs, track proof-of-delivery, and flag delays automatically.
- **Driver App** - lightweight mobile app for drivers to update status without calls or chat.
- **Analytics & Reports** - on-time rate, fuel, and utilization reports exported in one click.
- **Alerts & Geofencing** - instant notifications when a vehicle goes off-route or idles too long.

## Things to Highlight

- Trust is everything for this audience — surface real-looking client logos and a hard metric early, above the fold if possible.
- Big, confident display type in the hero. Generous whitespace; this should feel like enterprise software that's actually calm to use, not busy.
- One accent color (amber) only — used on CTAs and key data points. Everything else navy/neutral.
- Show the product, not abstract illustrations — a clean dashboard mockup beats a generic 3D graphic.
- Mobile matters: ops managers will open the pitch link on their phone.
